# Contributing

Thanks for your interest in improving this project.

## Ways to Contribute
- Report bugs.
- Suggest features or architectural improvements.
- Improve documentation.
- Submit pull requests.

## Before Opening a Pull Request
- Keep changes focused and well documented.
- Follow the existing coding style.
- Update `/docs` if interfaces, APIs, or message formats change.
- Do not include generated files, datasets, secrets, or credentials.

## By Contributing
You agree that your contribution may be modified, accepted, or rejected by the maintainers and, once merged, becomes part of this repository under its licensing terms.

## Important
This repository is source-available for review purposes only.
Contributing does **not** grant permission to reuse this code outside this repository.
